How it's built

Page Object Model

Locators and actions only — every assertion lives in the test, never the page object.

Data-driven

Parametrized cases loaded straight from data/*.json and data/*.csv, with readable ids.

Allure reporting

Step-by-step actions, severity from the test plan's priorities, feature labels, screenshots on failure.

No time.sleep

Playwright auto-waiting and expect() web-first assertions only.

CI-native

Smoke on every push, full regression on pull requests and nightly, via GitHub Actions.

Containerized

Ships as a Docker image on Playwright's official base — reproducible anywhere.

Defects logged

Real discrepancies the regression suite caught between the test plan's assumptions and the app's actual behavior — filed as GitHub Issues, not silently patched over.

Low "Reset App State" leaves stale "Remove" buttons on the inventory page #1 → Low Cart contents persist across logout/login instead of resetting per session #2 → Medium Checkout proceeds with an empty cart — no validation blocks it #3 →

Quickstart

# one command: builds, runs the full regression suite, then serves this
# site + the test report — nothing else to type
docker compose up

# then open:
#   http://localhost:8000/site/            (this page)
#   http://localhost:8000/reports/report.html  (test report)

# — or run it natively —
pip install -r requirements.txt
playwright install chromium
pytest -m smoke
