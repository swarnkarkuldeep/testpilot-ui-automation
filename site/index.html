How it's built

Page Object Model

Locators and actions only — every assertion lives in the test, never the page object.

Data-driven

Parametrized cases loaded straight from data/*.json and data/*.csv, with readable ids.

Allure reporting

Step-by-step actions, severity from the test plan's priorities, feature labels, screenshots on failure.

No time.sleep

Playwright auto-waiting and expect() web-first assertions only.

CI-native

Smoke on every push, full regression on pull requests and nightly, via GitHub Actions.

Containerized

Ships as a Docker image on Playwright's official base — reproducible anywhere.

Quickstart

# run the smoke suite locally
pip install -r requirements.txt
playwright install chromium
pytest -m smoke

# or run it in Docker — no local setup at all
docker build -t testpilot-ui-automation .
docker run --rm testpilot-ui-automation
